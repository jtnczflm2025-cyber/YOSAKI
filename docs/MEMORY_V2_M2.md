# Memory V2 Phase M2：隔离召回与影子编译

**当前状态：M2.1～M2.4 已完成隔离验收，正式旁路及上下文切换仍未获授权。** M2.3 扩展测试曾发现既有 R2 工具回合在原用户消息删除后回退到更早消息；独立 R2.1 持久锚点修复后，该断链测试与完整隔离回归通过。修复记录见 `MEMORY_V2_R21_M24.md`。

M2 仅在独立源码副本与临时 SQLite 验证。M1 的消息和活动原表仍是证据来源；人工记忆及 Phase 5 已批准投影保留原有权威。M2 不调用模型、工具或有隐式写入的 `learning_context()`，也不注册正式请求旁路。

## 分步门槛

1. **M2.1**：固定 `RecallRequest`、候选生成器、`RecallCandidate`、`RecallDecision`、`ContextBundle` 契约及合成金标准。
2. **M2.2**：词项／专名／明确回忆生成器读 M1 活动索引代；所有生成器须通过同一实时来源和权威资格过滤，过滤先于排序与数量限制。
3. **M2.3**：确定性原文节选和估算 Token 预算；隔离回放及临时数据库上的本地模拟请求做影子对照，不改变模型请求。
4. **M2.4**：汇总命中、零命中、过召回、来源正确、重复、节选忠实度、估算 Token、延迟及旧链差异。只提交将来切换方案。

`RAW/CLEANED/NARRATIVE/DIGEST` 是文本视图；M2 候选仅使用 `RAW`。同角色同一来源集合形成相同经历键，视图数量不得增加召回权重。语义相似、跨时间主题、情境变化和目标关联为未来独立生成器，不在 M2 实现。

## M2.1 合成金标准（实现时逐项断言）

| 场景 | 预期 |
| --- | --- |
| 中文「阿夜」、日文「美咲」及中日混排 | 两字词项可检索，专名触发须保守；角色名本身不导致每轮浮现 |
| 明确「还记得」与无关提问 | 前者可触发，后者零召回 |
| 同一经历的四种模拟视图 | 只保留一个经历键，保留有序原始来源 |
| 人工长期／本会话临时／合法批准记忆 | 保留正式参考性质；其他会话临时记忆不可见 |
| 待审、归档、异常谱系及跨角色记录 | 不进入正式参考或历史候选 |
| 编辑、删除、禁用、重新生成 | 旧来源指纹、旧节选立即失效 |
| `failed`、`unknown` 活动 | 可引用实际状态，不能叙述为成功，参数与结果载荷不出现 |
| 多批工具及重新生成 | 仅使用 R2 验证的用户回合，不用最近消息猜测 |
| 连续多轮与主动追问 | 被动冷却有效，明确追问绕过，换会话／角色不共享 |
| 超长正文含否定、条件及说话人 | 节选偏移逐字回指原文并标记不完整；不安全时跳过 |

这些是确定性规则能力的评测。语义相近但无词项重合、跨时间潜在主题及目标关联仅记录为未来扩展需求，不把当前零命中误写成已解决。

## 隔离实现与结果（2026-10-28）

`memory_v2_contract.py` 保留四视图和有序来源契约；当前召回只产出 `RAW`。`memory_v2_recall.py` 的明确回忆、实体线索与主动词项生成器均经 `memory_v2_read.py` 同一实时校验。正式人工长期／本会话临时记忆和有效的 Phase 5 投影放在独立 `formal_references` 通道；M1 消息／活动放在 `selected` 历史证据通道。M1 未就绪时正式参考仍可返回。Phase 5 偏好、策略等未由 `eligible_rows()` 覆盖，仍归原有流程。

被动模式只接受明确回忆词、话题中出现的显式别名，或足够大索引里独立出现的两字低频词。词项规则不是永久唯一的候选入口；语义相似、跨时间主题、情境变化、目标关联均有独立生成器扩展位。所有生成器仅给出来源线索，不能绕过共同过滤。冷却状态由调用方临时提供，键含角色、会话、经历与输入指纹；本阶段不落库、影子回放不更新正式冷却。

`memory_v2_context.py` 只编译 `RAW`，完整正文过预算时先在原样可见文本中取命中句及相邻句，返回说话人、起止偏移、内容指纹和不完整标记；不能可靠定位或保留语境时跳过。不用模型生成临时摘要。Token 数沿用本地字符启发式，非供应商实际计费。`memory_v2_shadow.py` 只输出来源 ID、拒绝原因和估算量；不记录查询或正文，不注册正式路由。

固定的 10 个合成场景复现：预期命中 5、实际命中 5、误命中 0、漏命中 0；最大编译估算 41 token，均值 27.67 token；最终重跑的本机最大单次召回与编译耗时 2.46 ms。首次评测曾在无关问题「今天天气如何」误召回含「今天」的记录，收紧被动专名触发后重跑达到上述结果。这些数字只描述合成夹具，不代表真实对话精度或 Provider Token 成本。现有旧链在这组数据中每次仍选取 1 条人工长期记忆；M2 单独列出该正式参考，历史证据仅在相关问题中出现，不拿历史助手自述替代已批准结论。

## 切换建议与未覆盖边界

本轮不在 `main.py` 注册旁路，也不改变聊天、Phase 2／3 或 Phase 6.5 的模型输入。将来须先完成 M1 正式启用门槛；再取得真实数据旁路的独立授权，校准各 Provider 的实际 Token 用量并评估经授权的真实历史。切换应按预览、普通聊天、工具继续、Phase 2／3 分入口、默认关闭、可立即回退到旧链；每一步分别验收 R1/R2、重复经历、来源失效和零额外模型／工具调用。

未覆盖：无词项重合的语义近邻、跨时间主题、复杂目标关联、真实 Provider Token、真实私人历史和正式服务延迟。来源正文与批准记忆可能描述同一经历而没有可证明的共同原始来源集合时，只给重复风险提示，不擅自合并权威。

### R2.1 阻塞修复及剩余门槛

`messages` 新增可空的原用户消息 ID、正文 SHA-256 和原角色 ID；首批及后续工具批次均在同事务持久化和验证。旧待继续批次缺少锚点时返回 409，已完成历史无需补全即可展示。修复后的 58 项完整隔离回归通过；固定 10 场景 M2.4 评测也重新通过。正式迁移、真实数据旁路、供应商实际 Token 及用户历史评测仍需单独授权，不以本次合成结果代替。
