## 页面发现并修复的缺口

1. 资格核对结束后，无计划时仍显示“读取中”；取消又可能发生在前端尚未取得计划ID时，保留旧忙碌提示。现分别显示可规划、不可用或本地已停止，并保留迟到回执的取消处理；不把本地停播描述为供应商已停止或免费。
2. 跨标签页关闭AI导致后端拒绝后续状态读取时，旧“正在规划”文案没有退出。现异常路径结束本地播放/等待，并请求取消已知计划；保留具体错误，结果未知不补发。
3. 真实普通聊天完成后，父组件才将autoStart置为true，AI子组件缺少该变化监听，停在“可规划朗读”。已接通迟到的autoStart，同时保留一次启动去重、取消及来源核验。
4. AI合成后未刷新原额度提示，普通自动朗读终态也可能留下全局“正在朗读”。现转发原预算刷新事件，并在普通自动朗读结束／停止／失败时清除当前播放身份；连续通话分支及Memory逻辑不改。正常播放结束不触发一次新的取消或合成。
