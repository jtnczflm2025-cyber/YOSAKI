# 欲望系统 Phase 5：可追溯的长期学习

Phase 5 以已确认的 Phase 4 `free` 反馈为来源。客观操作、模拟体验和系统估计分别标记；学习结果是参考，不是行动命令。旧聊天、单步唤醒、人工记忆、持续意愿及驱力 baseline 的含义不变。

## 数据流与迁移

1. Phase 4 反馈在同一 SQLite 事务中标记 `applied` 后，Phase 5 无模型地归集 `learning_evidence`，来源 ID 固定为 `phase4:{feedback_id}`。读取长期学习页会分批补录旧的已确认反馈；唯一反馈 ID 和每会话主题权重上限防止重复计数。`skipped` 与结果未知的反馈不形成正负偏好证据。
2. 每条有已返回操作的反馈产生可审阅的经历记忆候选。`fact` 保存操作数和结果；`interpretation` 保存明确标为模拟评价的自述。相反评分的同主题经历保留 `conflict_ids`，不会覆盖旧来源。接受候选时写入现有 `memories` 长期作用域，并用 `learning_memories.memory_id` 连接来源、合并和版本；归档会停用该记忆。用户原有记忆保持原样。
3. 同主题、同环境的证据产生待审偏好建议。正式 `learning_preferences` 仅在用户批准后变化，和 `drive_states.baseline`、旧 `/preferences` 分开。批准、拒绝、调整和撤销写入 `learning_preference_history`；撤销停用该次贡献，并从仍有效来源重算，不删除原始活动。
4. 手动批量整理可提出同义主题归类。归类本身需审阅；若来源已进入正式偏好，须先撤销相关更新再重新归类，避免静默改变既有历史判断。
5. 策略候选由手动批量整理提出。Phase 3 决策的可选 `strategyId` 必须来自当前提供的已批准策略；实际操作写入该 ID。只有标记采用的成功／失败操作进入策略使用统计。用户再明确选择“审阅并更新效果”，估计才更新。策略可暂停、恢复或退役，不强制使用。
6. 已确认反馈若关联现有持续意愿目标，会生成待审的目标进度参考，包含真实完成步骤和最近检查点。保存参考不改变目标的 `stage` 或 `status`；是否维持、修改或放弃仍由 Phase 2 的明确意愿决定处理。

新增表由 `learning.init_db` 兼容创建，角色删除按外键清理；角色复制不会复制经历。加密 `.ybackup` 使用完整 SQLite 快照，因此包含新表。恢复备份前取消本进程的学习模型请求；模型整理进程中断后标为失败，不自动重放可能计费的请求。

## 偏好与策略规则

偏好按 `subject` 和 `context_key` 分开估计。每个独立会话对同一组合最多贡献一次；有体验评分时，主动选择权重上限 0.35，选择来源未知为 0.15。缺失评分不计正负。规则 `learning-v1`：

```text
estimate = (1.5 × 0.5 + Σ weight × enjoyment) / (1.5 + Σ weight)
confidence = min(0.9, Σ weight / (Σ weight + 1.2))
```

一条证据不能直接形成高置信度偏好。正反评分同时存在时标记 `uncertain`；至少两次独立评分可标记 `emerging`；至少五次且置信度达到 0.55 才能标记 `established`。时间流逝不改变估计。策略已确认使用的效果采用中性先验 `(1 + 成功次数) / (2 + 已知结果次数)`，置信度为 `min(0.8, 已知结果次数 / (已知结果次数 + 3))`；未知结果不计入成功或失败。策略统计按明确的操作关联计算，不从目标完成推断。

## 模型、上下文与 API

反馈确认后的归集与偏好计算不调用模型。`POST /api/desires/{角色}/learning/consolidate` 由用户手动选模型、一次调用和 128～4096 输出 token 上限，结构化返回零个或多个记忆／策略／主题归类候选。超时、无效引用或结构错误记录失败，正式结果不变。同一请求 ID 不重复调用。模型输出只是候选；服务端校验来源必须属于本角色。

`GET /api/desires/{角色}/learning` 返回证据、待审建议和历史对象；`/learning/context?topic=...` 预览下一次判断所用的有限参考。按对象提供偏好决策、时间线、修订版本、回滚，记忆决策与合并，策略决策、目标进度决策，以及最多 500 次评分的隔离模拟接口。所有写请求带 `schemaVersion=5`、`requestId`、`expectedVersion`；冲突返回 409。

Phase 2 与 Phase 3 只读取已批准、与主题相关且有数量上限的偏好、策略、记忆和目标进度。聊天继续使用现有记忆注入链：人工记忆保持原用法，新接受的经历记忆按话题最多选三条。来源、版本、规则和置信度可供 Phase 6 读取；Phase 6 不应把模拟自述当成真实主观测量。
