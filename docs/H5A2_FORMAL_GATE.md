## 当前运行契约

- H5 V2 入口默认关闭。启用后，工作目录须通过 Windows ACL 和卷加密检查：拒绝继承或额外 Allow/Deny 规则；只接受当前账户、OWNER RIGHTS、SYSTEM、Administrators 的显式规则。加密状态必须能证明为受保护且完全加密的 BitLocker 卷，或工作目录具备 EFS 加密属性；查询失败按未验证拒绝。**本机当前无法查询 C: 的 BitLocker 状态，且用户没有可用的加密测试目录，故目标环境门槛未通过。** Linux/Docker 主机卷加密不能由容器内部证明，当前也拒绝启用，须另行设计并审核主机证明。
- V2 文件格式的理论边界仍是 16 GiB；H5-A2 HTTP 和定时入口暂设更小的**操作准入上限**：数据库连同当前 WAL 最多 1 GiB，加密上传文件最多 1 GiB + 64 MiB。相同的 1 GiB 上限还在在线快照完成后、V2 清单解压前和 V1 候选发布前检查，防止小密文声明巨型解压库。它是保守的代码限额，**不是正式验收容量**。正式上限须在实际受保护目标卷用阶梯合成数据、同卷/跨卷空间和浏览器传输复测后确定。
- 入口级 ASGI 中间件在 FastAPI multipart 解析前要求单一 `Content-Length`，拒绝超限、重复长度头及 Transfer-Encoding；验权与 Origin 检查在工作目录操作之前。上传前按同卷或跨卷分别预留系统临时目录中仍加密的 multipart 文件、H5 工作目录中的上传密文、认证前压缩流、候选库和独立验证副本。备份创建预留在线快照、加密临时文件、解密候选及验证副本的合计空间；已有工作文件占用已反映在磁盘空闲量中。空间预检不能替代操作中磁盘故障处理。
- 手动和定时 V2 任务共用一次一个的重型操作配额。下载票据只在单进程内，启动环境的 worker 声明必须为 1，且受保护工作目录上的非阻塞进程锁拒绝第二 worker。该锁防止第二进程使用 H5，但正式启动参数仍须现场核对。准备/验证的工作循环有 30 分钟截止检查；上传单次读取有 60 秒超时；当前会话可请求取消运行中的准备/验证。取消与超时清理本次临时文件，不发布不完整备份。
- 下载票据是与当前服务端 session 绑定的单次凭据，600 秒过期。浏览器用同源 POST 原生表单提交，不放在 URL、历史或默认路径访问日志中。每次最多保留一个待下载文件；当前会话可取消待下载票据。中断下载不恢复已消费票据，需重新准备；崩溃遗留的**加密**下载文件只在 24 小时后由受限前缀清理。浏览器以 `no-store` 接收响应，不用 JS Blob 装入整份 V2 文件。V2 不安全或超限的 503 不再自动降级成旧 V1；只有 V2 明确未启用时才允许旧版导出。
- 命令行隔离恢复现在要求受保护工作目录，并把新目标放在该目录的直接子目录；恢复前核对容量。活动数据库替换仍被旧导入 API 拒绝。备份后的新增聊天、记忆、活动与审核不能由整库回退自动覆盖。

## 正式门槛与 H5-B

正式启用前：提供可验证加密且 ACL 合格的目标工作目录；在该卷完成容量阶梯、实际同卷/跨卷峰值、磁盘不足及中断演练；核对单 worker 启动配置与代理超时/体积限制；在真实浏览器证明大文件传输有限内存；完成正式库启用前加密备份、全新目录独立恢复、旧库/WAL 迁移、来源/角色权限和回滚方案，并单独批准部署。恢复后新增数据须保留或经单独明确处置，不能默认整库覆盖。

H5-B 仅作为待授权的小样本流程：用户将来明确指定 1～2 个文件及范围后，才可在外部源码副本、独立 SQLite、无模型/向量/外部网络环境中进行只读预览和受控 RAW 导入。H5-A2 隔离完成不会自动授权任何私人文件读取、正式迁移、历史批量导入或上下文切换。
