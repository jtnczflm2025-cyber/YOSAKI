# Memory V2 三域职责与 M4／M5 路线

P1-A2 补充：RAW、System-generated Chronicle、Temporal Memory、Aya's Personal Curation 是 Chronicle 的证据与用途分层，不替代以下三域权威。渐进字段允许逐步完成，但浏览、搜索、候选、P2投影、正式上下文资格分别判定；正式上下文保持关闭。owner 负责加工质量门槛；阿夜的个人重要性、奠基事件、特殊保留和个人备注不由系统赋值。实现与当前权限验收暂停记录见 `MEMORY_V2_P1A2.md`。

> 架构修订：2026-10-28。本文描述后续目标契约和路线，不表示 M3、M4、M5、心潮念连接器或跨域来源接口已经实现。现有 M1／M2、R1／R2.1 和 Phase 1～6.5 代码及正式上下文链保持不变。

## 三域权威边界

| 领域 | 所管内容与用途 | 权威边界 |
| --- | --- | --- |
| **Chronicle／溯时流源** | 以现有聊天消息和 Phase 3 活动记录为原始证据，建立来源索引、时间分段、忠实精修、阿夜第一人称记事与分级摘要。记录谁在何时说过、做过什么及来源支持的结果。 | 原始消息与活动记录仍由现有模块管理；索引、标题和 CLEANED／NARRATIVE／DIGEST 都是可失效的派生视图。不得推断未明确记录的内心，或把陈述、模拟事件与外部已验证事实混用。 |
| **Personal Notebook／心潮念** | 阿夜主动记录当下感受、想法与反思的独立空间。未来仅通过可选连接器按用途引用。 | 笔记由心潮念管理；YOSAKI 不自动生成、改写、全局索引、训练、周期摘要或送入 Phase 5。一般助手发言和系统派生第一人称文本不能凭口吻认定为阿夜主动笔记。本阶段不建立连接器。 |
| **Experiential Memory／经验关联视图** | 未来 M4 将 Phase 1～6.5 的目标、决策、操作、结果、反馈及学习记录组织成可查询的经历链。 | 各 Phase 的原始记录和状态继续权威；关联只提供可验证的参考，不复制第二套驱力、目标、心理、审批或执行状态，也不成为独立召回引擎。Phase 5 继续批准正式长期学习和策略。 |

M2 将作为跨域**只读召回协调层**，按用途、当前权限、来源可信标签和 Token 预算选择各域提供的候选；不得取得这些领域的写入、审批或工具执行权。M3 只负责 Chronicle 的 RAW／CLEANED／NARRATIVE／DIGEST 忠实表达，不承担个人笔记、行为经验学习或心理解释。M5 负责展示与对照，不改变来源权威。

## 跨域引用与证据属性：目标契约

未来引用至少包含 `characterId`、`sourceDomain`、`sourceKind`、`sourceRecordId`、`sourceVersion` 或内容与状态指纹、`authorKind`、`evidenceKind`、访问权限及允许用途、发生／记录时间与时间依据，以及会话或父记录关联。`sourceDomain` 指原始记录的管理方，例如 conversation、各 Phase 或 personal_notebook；Chronicle 派生版本与经验关联本身须标记为派生或关联，不得冒充原始证据。跨域去重键须包含 domain，避免不同系统相同记录 ID 相撞。M1/M2 现有 `(kind,id)` 和角色契约本轮不变，未来由适配层扩展。

证据属性分维度表示，不能用单一 `evidenceKind` 承担所有含义：

| 维度 | 必须回答的问题 |
| --- | --- |
| 来源性质与作者 `sourceNature`／`authorKind` | 是聊天陈述、阿夜主动笔记、活动记录、系统派生文本，还是其他记录？用户、助手、阿夜主动记录者或系统分别是谁？第一人称口吻不是作者证明。 |
| 执行结果 `outcomeStatus` | 操作成功、失败、未知、待确认或不适用？`failed`／`unknown` 不能提升为成功。 |
| 现实／模拟边界 `realityBoundary` | 是可核查操作记录、当事人陈述、模拟状态、推断还是尚不明确？Phase 6 模拟状态不等于真实外部事实。 |
| 批准状态 `approvalStatus` | 是否属于 Phase 5 已批准结论，或只是候选、撤销、归档及不适用？派生文本的质量复核不等于 Phase 5 批准。 |
| 来源有效性 `sourceValidity` | 当前角色、权限、版本、内容与状态指纹是否仍匹配？失效时不得返回旧正文。 |

这些是 M4 的目标字段语义，不是立即增加的 SQLite 列或对 M1/M2 API 的变更。一次读取应重新检查原始来源与权限；派生索引、经验关联和历史授权均不能单独证明当前可访问。

### 关联证据与因果边界

每条重要经验关联至少保留 `relationType`、两端来源引用、证据引用、`linkBasis`、`verificationStatus` 和版本／失效指纹。`linkBasis` 明确区分：**原系统显式记录的关联**、**仅时间接近的关联**、**未经核实的候选关联**、**经明确确认的关联**。确认记录还须保留确认者、范围与时间；既有原系统关联不应无依据扩大其语义。

时间顺序、相邻时间戳、词项相似及模型建议只能提供线索，不能自动推出“欲望导致决策”“行动导致反馈”或其他确定因果。没有直接来源或明确确认时，关系类型应限于 `co_occurs`／`candidate_related` 等非因果描述；任何升级都需可追溯证据与验证状态。关系撤销、原记录修订、权限变化或状态变化使相应边失效，不覆盖原记录。

### 心潮念可撤销授权

未来连接器必须分别取得**建立关联、查看片段或全文、参与召回、进入模型上下文**的用途授权；训练、周期摘要和作为 Phase 5 学习证据另行明确授权，默认关闭。建立过关联仅能证明曾经有该引用，不授予永久全文读取权。每次查看、召回或展开都重新验证笔记当前授权、角色、版本及存在性；撤权或来源失效后不返回旧正文、标题、片段或缓存。失权时可保留不含正文的失效诊断，但不自动继续索引、摘要、改写或学习。

## Phase M4 — Experiential Memory Bridge

| 增量 | 目标产物 | 验收与停止条件 |
| --- | --- | --- |
| **M4.1 权威审计** | 核对 Phase 1～6.5 的原表、记录 ID、角色、状态、版本、已有来源关联、权限与写入入口；标清决策、执行、结果、反馈和学习的原系统连接及不确定性。 | 交付逐表证据地图与缺口清单；任何不能证明的归属或因果都列为待核实，不设计自动补全。 |
| **M4.2 经验关联契约** | 设计幂等、只读的跨域关联与读时失效检查；每边记录关系类型、证据及验证状态，不复制核心状态。为心潮念仅预留可选、可撤销引用接口。 | 同源重复不重复建链；删除、修订、撤权、角色变化使旧关联停止出正文；时间接近或模型建议不能自动升级为确认或因果。 |
| **M4.3 M2 影子召回** | 作为 M2 的候选提供者，为 Phase 2／3 按需提供历史经验和 Phase 5 已批准正式参考，沿用 M2 权限、信任过滤、去重、冷却和 Token 预算。 | 召回只提供决策参考，不改意愿判断、驱力、心理状态，不执行工具；不注册正式请求旁路或重放历史反馈。 |
| **M4.4 隔离回归与切换提案** | 用临时 SQLite、合成来源及模拟服务验证失败／未知操作、模拟状态、跨角色、来源失效、审批撤销、重复反馈和多条候选关联；提出逐入口启用及回退方案。 | 角色泄漏、证据升级、重复学习／反馈／心理入账、额外工具调用均为零；失败即停止，正式接入另行批准。 |

M4 不建立独立欲望记忆数据库、平行审批或执行器；Phase 5 仍管理正式长期学习。恢复旧备份后，派生关联只能从当时有效的权威记录安全重建，不得把旧缓存当新证据。
M4 的经验关联桥接不依赖 M3.6 真实模型精修上线；M4 可以按自身计划独立审核和隔离开发，但本文件不批准直接实施。

## M5 展示路线

保留时间树、四文本视图切换、原文并排对照、逐句溯源高亮、派生版本管理、来源状态与失效提示。增补同一事件的**目标／决策／执行／结果／反馈／已批准学习**关联查看，显示关系类型、证据依据和确认状态；时间接近与候选关系必须明显区别于明确确认。界面分别标示 Chronicle 证据、经验关联和个人笔记。心潮念只展示当前明确允许引用的内容；撤权后不再展示旧片段，不默认合并、改写、摘要或加入全局召回。

## 当前实现与启用门槛

- M1 已在隔离环境实现消息与安全活动元数据的可重建索引；原文仍由现有表管理。M2 仅在隔离环境提供 RAW 候选和影子编译，正式上下文链未切换。R1/R2.1 及 Phase 1～6.5 现有权威边界不变。M3 按已批准的忠实精修计划继续，本修订不扩其范围。
- 新版后端启动会运行现有 `init_db()`。正式数据库部署前仍须独立加密备份、恢复演练、迁移幂等、原表与权限校验、回滚演练；真实数据影子旁路和正式上下文切换分别需要批准。本路线文档不授权运行这些步骤，也不实施 M4/M5。
