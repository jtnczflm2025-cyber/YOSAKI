# YOSAKI 全界面银灰玻璃改版计划

适用范围：欢迎页、工作台、全部 11 类功能窗口、独立功能页、Chronicle、语音控件、导入与备份、确认浮层及各类状态。以用户提供的第二张参考图为视觉方向；第一张只补充浮窗材质。当前实施日期：2026-11-17。

## 1. 目标与边界

把 YOSAKI 统一为安静、通透、精致的私人 AI 工作台，保留中文界面、阿夜的自主性、现有登录与初始化、可组合浮窗和全部功能。页面主要入口采用全页工作区，窗口标题栏保留“在浮窗打开”；浮窗仍可拖动、调整大小、最小化、最大化和恢复。

这次改版调整界面与导航，不迁移日常数据库，不启用后台任务，不改变模型、MCP、Voice、Memory V2 的权限、结算或逐次确认规则。功能可见性继续服从原有开关。记忆年历的前端构建开关和正式服务端准入不是 UI 改版的副作用。

## 2. 分步骤实施

| 步骤 | 实施内容 | 交付与核对 |
| --- | --- | --- |
| 1 盘点与保护 | 检查现有路由、窗口、业务状态、局部 CSS 和未提交修改；保存改版前前端副本 | 不覆盖现有工作；以改版前副本核对本轮变化 |
| 2 统一基础变量 | 建立浅色／深色共享颜色、文字、间距、圆角、阴影变量；默认珍珠白，提供主题切换 | `frontend/src/ui/tokens.css`、`theme.ts` |
| 3 材质与资源 | 将所给 React 玻璃参考中的位移计算适配为 Vue；评估地球库、公开地理数据及付费替代方案 | `GlassSurface.vue`、`glassRefraction.ts`、本地资源 |
| 4 欢迎页 | 左侧短文案和主按钮，右侧大地球；3 张固定 HTML 功能卡；保留认证 | 欢迎页宽屏和手机截图；按钮可进入真实功能 |
| 5 工作台 | 分组侧栏、同一地球、常用直达卡、真实当前状态；打开窗口列表按需展开 | 全部入口可达；无虚构数量和“全球服务节点”暗示 |
| 6 全功能迁移 | 主窗口及角色、模型、记忆、欲望、学习、心理、工具、插件、语音、设置、导入、备份统一色板和控件 | 全页与浮窗共用现有业务组件；不平行创建另一套业务实现 |
| 7 阅读精修 | 中日文 17px／1.75，稳定正文底面；输入区与工具栏保留玻璃；模型详情折叠 | 真实渲染合成长文本、手机阅读、Chronicle 精修正文 |
| 8 交互与降级 | 地球拖动／惯性／自转／暂停／复位，键盘方向键；不可见暂停，减少动态关闭自动运动；失败用静态图 | 核对拖动不会触发卡片、正文无地球、导航独立可用 |
| 9 验收与交接 | 类型检查与构建、隔离浏览器验收、视觉对照、文档与开发入口约束 | 根目录 `design-qa.md` 和 `docs/UI_DESIGN_STANDARD.md` |

## 3. 地球方案调研与选型

| 资源 | 适配情况 | 本轮决定 |
| --- | --- | --- |
| [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html) | 官方控制器支持旋转、阻尼和自动旋转；可关闭平移和缩放 | 采用；由 Vue 控制唯一渲染循环，传入帧间隔 |
| [three-globe](https://github.com/vasturiano/three-globe) | Three.js 对象形式，支持经纬网、球面坐标和气氛层，可与自定义点阵／轨道组合 | 采用；禁用库内独立动画，避免隐藏页仍持续刷新 |
| [COBE](https://cobe.vercel.app/) | 提供轻量点阵球、标记与弧线，可用于 Vue；适合控制包体的替代路线 | 备选；当前选择 Three.js 以便控制银灰材质、灯光与轨道 |
| [Spline](https://spline.design/) | 可作为可视化场景制作及付费制作路线；需要另行核实当前导出能力、运行方式和授权 | 未购买，未作为运行依赖；现有方案不需要付费素材才能工作 |
| [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) | 公共领域地理数据；本轮离线生成陆地点阵 | 采用；客户端只读取本地 JSON，不请求地图服务 |

选择依据是可控的材质和交互、现有 Vue 技术栈及离线可用性，不是“免费优先”。库负责几何与交互，银灰材质、亮边、点阵和排版由项目统一控制；商品地球模型本身不能替代这些集成工作。

## 4. 页面与窗口清单

- 日常：聊天、记忆年历（原有开关允许时）。
- 角色与内在：角色卡、欲望与意愿，以及内部的观察、自由活动和体验反馈；长期学习；心理状态。
- 能力与连接：模型配置及本机套餐连接、MCP 与工具、插件、语音设置与消息播放器／录音草稿／通话设置。
- 管理：提示词与上下文、系统设置、聊天档案、备份及定时备份。
- 横向状态：登录／初始化、加载、空状态、错误、未保存、等待确认、执行中、录音中、中断、禁用、恢复与确认浮层。

不因入口重新分组而删除低频功能；复杂设置可折叠，但权限、录音、失败和未保存提示不能被视觉简化吞掉。

## 5. 验收方法

使用 `scripts/ui_acceptance_preview.py` 创建新的临时 SQLite 工作区，在 `127.0.0.1:65117` 提供真实构建产物与真实 API。脚本先执行运行模式预检，阻断非回环网络，关闭 Voice 和后台任务，填充明确标识的合成中日文阅读样本。禁止改用日常数据库做 UI 测试。

检查 1440×900 桌面、390×844 手机以及中等宽度；分别检查浅色、深色、正文、表单、浮窗和错误／空状态。重点检查实际正文计算样式、溢出、导航可达性、主题跨入口同步、窗口操作、地球暂停及资源失败降级。视觉证据和尚未覆盖的环境写入 `design-qa.md`，不把构建通过等同于全业务真实验收。

## 6. 实施说明

本轮沿用 Vue 3、TypeScript、现有手写 CSS、Lucide；没有引入 React、Tailwind 或另一套全局 reset。原有组件的业务脚本保留，局部样式迁移到共享语义变量；新外壳集中在 `frontend/src/ui/`。

地球模块懒加载，当前构建约 533 KB gzip；欢迎／工作台首次进入前显示本地静态地球。该模块不进入聊天和记忆正文视图的渲染路径。最终验证范围与构建告警以 QA 记录为准。

聊天补充实施：对话管理、语音配置、自动朗读与逐条补查移入共用抽屉，活动状态和停止操作保留在正文输入区／抽屉固定底部。使用 `scripts/ui_chat_fixture.mjs` 将带合成状态的前端构建到临时目录，仅监听回环端口；所有 API 写入、外部请求、录音和语音播放均阻断。该夹具专门补足第一轮关闭 Voice 时未暴露的正文挤压问题，不替代真实服务验收，也不写入正式构建源码或日常数据库。

## 2026-11-18～19 Chat Enhancement 隔离接线

复用 ChatDrawer 与 ui 银灰变量，新增 chat/ 下的消息／请求面板及附件输入。改动包括不可变编辑、版本选择、分支、引用、翻译、模型覆盖、摘要、计量与截图预览。未替换工作台导航或 Chronicle。消息正文与编辑／翻译文本仍 17px／1.75，移动按钮最小 44px。实际合成验收与截图见 `CHAT_ENHANCEMENT_CANDIDATE.md`、候选 evidence/browser-*.log；真实语音及系统截图选择器未执行。
